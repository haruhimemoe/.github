# Security

Please report vulnerabilities privately instead of opening an issue:

1. **GitHub:** use the repository's **Security** tab, then **Report a vulnerability** (private vulnerability reporting).
2. **Email:** contact@haruhime.moe, if you can't use GitHub.

Include steps to reproduce and the impact you expect. You'll get a reply within 7 days.

This is the default policy for haruhimemoe repositories that don't have their own `SECURITY.md`. Report problems in third-party services (osu!, the beatmap mirror) to them.
