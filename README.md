# haruhimemoe/.github

The haruhimemoe organization's GitHub profile and default community health files. The tools and packages live in their own repositories at [github.com/haruhimemoe](https://github.com/haruhimemoe).

- [`profile/README.md`](profile/README.md): the profile shown on [github.com/haruhimemoe](https://github.com/haruhimemoe).
- [`llms.txt`](llms.txt): the organization's tools, packages, Claude Code plugin and Discord server in [llms.txt](https://llmstxt.org/) format.

GitHub uses these for any haruhimemoe repository that doesn't have its own:

- [`SECURITY.md`](SECURITY.md): how to report a vulnerability.
- [`CONTRIBUTING.md`](CONTRIBUTING.md): how to contribute.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/): bug and feature forms, with links to the Discord server and to security reporting.
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md): the pull request template.
